# Рекомендательная система контента

## Тема
Разработка и сравнительный анализ алгоритмов рекомендательной системы контента (фильмы, сериалы, книги, музыка) на основе предпочтений пользователя.

## Список требований к программе

### Функциональные требования
1. Определение возрастной группы пользователя (7 групп: дети, подростки, молодёжь, взрослые, средний возраст, старшее поколение, пожилые).
2. Учёт возрастных ограничений контента (0+, 6+, 12+, 16+, 18+).
3. Выбор предпочитаемых жанров из 20 категорий.
4. Реализация **четырёх алгоритмов** рекомендаций:
   - **Правила**: возраст + жанры + целевая группа.
   - **Коллаборативная фильтрация**: на основе реальных оценок пользователей (косинусное сходство).
   - **Популярность**: топ элементов по рейтингу популярности.
   - **Гибридный**: взвешенная комбинация трёх предыдущих (веса 0.5, 0.3, 0.2).
5. Вывод рекомендаций (не более 5 позиций на категорию) для каждого алгоритма с **метриками качества**:
   - **Точность** – доля рекомендованных элементов, чей жанр совпал с предпочтениями пользователя.
   - **Средняя популярность** – среднее арифметическое поля popularity среди выданных рекомендаций.
6. База данных содержит более 80 элементов (фильмы, сериалы, книги, музыка) с российским и зарубежным контентом.
7. Возможность **добавления нового контента** пользователем (с проверкой дубликатов) и **оценивания** любого элемента (оценки сохраняются в файл).

## Описание алгоритмов

### Алгоритм 1 – на основе правил
Последовательная фильтрация базы контента по четырём критериям:
1. Тип контента (фильм, сериал, книга, музыка) совпадает с запрошенным.
2. Возрастной рейтинг элемента не превышает максимально допустимый для пользователя (определяется по возрасту: 0–12 лет – рейтинг 6+, 13–17 – 12+, от 18 – 18+).
3. Целевая группа элемента строго совпадает с группой пользователя.
4. Жанр элемента присутствует в списке предпочтений, выбранном пользователем.  
Останавливается после набора 5 позиций.

### Алгоритм 2 – коллаборативная фильтрация (на основе реальных оценок)
- Загружаются все оценки, оставленные разными пользователями (из файла `ratings.txt`).
- Для текущего пользователя вычисляется **косинусное сходство** с каждым другим пользователем на основе общих оценённых элементов.
- Выбираются два наиболее похожих пользователя («соседа»).
- Рекомендуются элементы, которые соседи оценили на 4 или 5, но текущий пользователь ещё не оценивал (и которые подходят по возрасту и типу контента).
- Элементы сортируются по сумме оценок соседей, выдаются первые 5.

### Алгоритм 3 – по популярности
- Из базы выбираются все элементы заданного типа, подходящие по возрасту (без учёта жанров и целевой группы).
- Сортировка по полю `popularity` (1–10) по убыванию.
- Первые 5 названий выдаются как рекомендации.

### Алгоритм 4 – гибридный
- Объединяет результаты первых трёх алгоритмов с весами: Правила – 0.5, Коллаборативная – 0.3, Популярность – 0.2.
- Каждый элемент получает итоговый вес: сумма взвешенных вкладов с учётом позиции в списке.
- Сортировка по убыванию итогового веса, выдаются первые 5 названий.

## Структура проекта и файлы

Репозиторий содержит следующие файлы:
- `Source.cpp` – полный исходный код программы на C++.
- `database.txt` – текстовый файл с базой контента (более 80 записей, разделитель `|`).
- `ratings.txt` – текстовый файл с оценками пользователей (заполняется автоматически, изначально содержит 10 демонстрационных пользователей).
- `README.md` – текущее описание.
